# Hiagi AI Marketing - Landing Page

Landing page hiện đại cho nền tảng AI Marketing với thiết kế SaaS chuyên nghiệp.

## 🚀 Tính năng

- **Hero Section** với gradient background và animations
- **About Section** giới thiệu về Hiagi và giá trị cốt lõi
- **Features Section** hiển thị 8 tính năng nổi bật theo nhóm
- **CTA Section** kêu gọi hành động với thiết kế gradient nổi bật
- **Registration Form** với validation và trạng thái loading
- **Footer** với links và thông tin liên hệ
- **Responsive Design** hoàn hảo trên mọi thiết bị
- **Animations & Effects** smooth scrolling, hover effects, gradient animations

## 🛠️ Công nghệ sử dụng

- **Next.js 16** - Framework React hiện đại
- **TypeScript** - Type safety
- **Tailwind CSS v4** - Styling utility-first
- **React Hooks** - State management và side effects

## 📦 Cài đặt

```bash
# Clone repository (nếu cần)
# git clone [url]

# Di chuyển vào thư mục project
cd my-app

# Cài đặt dependencies
npm install

# Chạy development server
npm run dev
```

## 🌐 Truy cập

Mở [http://localhost:3000](http://localhost:3000) để xem landing page.

## 📋 Sections chính

### 1. Hero Section
- Brand name với gradient text
- Headline chính và sub-headline
- CTA button với smooth scroll
- Mockup dashboard hiển thị metrics
- Animated background elements

### 2. About Section
- Giới thiệu về Hiagi
- 4 giá trị cốt lõi với icons
- Card-based layout với hover effects

### 3. Features Section
- 8 tính năng được nhóm thành 3 categories:
  - CREATE (Tạo nội dung): 2 features
  - PLAN & MANAGE: 3 features
  - ANALYZE & OPTIMIZE: 3 features
- Icon-based cards với descriptions

### 4. CTA Section
- Gradient background nổi bật
- Limited time offer messaging
- Benefits list với check icons
- Primary CTA button

### 5. Registration Form
- 5 fields: Họ tên, Email, Số điện thoại, Doanh nghiệp, Ngành hàng
- Client-side validation
- Loading states và success message
- Responsive form layout

### 6. Footer
- Brand information
- Quick links
- Social media icons
- Copyright và back-to-top button
- Final slogan

## 🔧 Customization

### Thay đổi màu sắc
Chỉnh sửa các gradient trong `globals.css` và component files.

### Cập nhật nội dung
Thay đổi text trong các component files theo yêu cầu.

### Thêm animations
Sử dụng các keyframes đã định nghĩa trong `globals.css`.

## 📱 Responsive Breakpoints

- Mobile: < 640px
- Tablet: 640px - 1024px
- Desktop: > 1024px
